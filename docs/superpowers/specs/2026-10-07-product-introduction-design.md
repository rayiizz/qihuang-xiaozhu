# 产品介绍四宫格设计说明

日期：2026-10-07

## 目标

在现有“产品介绍”页面中加入四款真实产品的基础资料，让访客能够快速了解产品名称、类型、主要成分或结构、基本用法与注意事项。内容以资料提炼为主，避免把宣传语改写成医疗功效承诺。

## 信息来源与产品范围

- `ppt.zip`：闪亮菁华眼贴、易灸灸蕲艾敷贴。
- MAKA 页面：易灸灸蕲艾敷贴、全元倍生·小双瓶。
- 用户提供的图片：芝麻丸。

最终展示四款不重复产品：闪亮菁华眼贴、易灸灸蕲艾敷贴、全元倍生·小双瓶、芝麻丸。

## 页面结构

保留“产品介绍”页面现有标题、说明及产品理念等信息，在其上方增加“四款产品”内容区：

1. 区块标题、简短导语和统一使用边界提示。
2. 四张产品卡片组成的响应式网格：桌面端两列，窄屏单列。
3. 每张卡片固定显示产品图、名称、类型与一句简述。
4. 卡片内使用原生 `details/summary` 展开基础资料，包括“主要成分/结构”“基本用法”“注意事项”。
5. 原有产品理念、隐私方式、适用范围和使用边界继续保留在产品卡片之后。

## 视觉与交互

- 延续现有米白纸张、玉色和朱砂色视觉体系，不引入与站点冲突的新设计语言。
- 产品图采用统一比例的裁切容器；通过浅色衬底、圆角和细边框把来源不同的图片整理为一套视觉系统。
- 卡片使用轻微层级与留白，不使用强烈阴影或商业促销式标签。
- `details/summary` 支持键盘操作，并提供清晰的展开状态。
- 对移动端缩减内边距、改为单列，确保正文和按钮不拥挤。

## 文案原则

- 仅呈现资料中能够直接确认的名称、产品形态、组成及使用方式。
- 将宣传性场景改写为日常、中性的产品描述。
- 不使用“治疗、治愈、改善疾病”等结论性表达。
- 温度、时长和食用量等可能随批次或包装变化的信息，统一提示以实际包装说明为准。
- 眼贴和敷贴提示仅供外用、避开破损皮肤或眼内；出现不适时停止使用。
- 食品类产品提示关注原料过敏及个人饮食限制；不替代药物或医疗建议。

## 数据与实现

四款产品资料维护为独立的静态数据数组，由现有前端脚本渲染到产品网格。这样可以保持 HTML 结构简洁，并方便以后增删产品。图片作为站点本地资源存入 `assets/products/`，不依赖外部页面在线可用性。

若脚本不可用，页面仍保留产品区标题和统一提示；正常情况下由脚本一次性生成卡片，不产生网络请求或持久化数据。

## 验证

- 添加数据结构测试，确认四款产品均存在，且每款具备名称、类型、图片、组成、用法和注意事项。
- 添加页面结构测试，确认产品网格容器与统一提示存在。
- 运行现有测试，避免影响穴位浏览、收藏与免责声明等功能。
- 在浏览器中检查桌面和手机宽度下的四宫格、展开交互、图片裁切与文字可读性。
