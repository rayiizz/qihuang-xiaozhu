# 免责声明页面设计规范

## 目标

为本地中医穴位参考应用增加一个清晰、可访问的免责声明入口。用户可从首页底部进入独立的站内免责声明视图，了解产品定位、医疗安全边界、内容局限与隐私处理方式，并可返回首页。

## 范围

本次仅增加免责声明入口、免责声明视图及必要的站内导航，不调整问诊流程、穴位推荐逻辑、穴位数据或产品介绍内容。

## 交互与页面结构

- 在应用公共页脚中显示“免责声明”链接，使首页和问诊结果等主要视图均可找到入口。
- 点击链接后切换到站内独立视图《免责声明与使用须知》，不打开新窗口，也不依赖网络。
- 免责声明视图顶部提供“返回首页”操作。返回时进入首页，不恢复未完成的问诊步骤。
- 链接和返回操作均支持键盘访问，并保留清晰的焦点样式。
- 页面继续保持现有中式健康应用的色彩、排版和响应式布局；免责声明使用易读的分节卡片，而不是密集的小字号文字。

## 免责声明文案

### 1. 产品性质

本产品仅提供中医穴位与日常健康知识参考，不是医疗机构或互联网医院，不建立医患关系。“在线问诊”仅为功能名称，实际属于健康信息引导。

### 2. 不构成诊疗建议

页面内容、穴位推荐和操作说明不构成医学诊断、处方、个体化治疗方案或疗效保证，也不能代替执业医师、中医师或其他合格医疗专业人员的判断。用户不应因使用本产品而延误、取消或改变正规诊疗。

### 3. 紧急与严重症状

若出现胸痛、呼吸困难、意识异常、突发肢体无力或言语不清、严重出血、严重过敏、持续高热、剧烈或快速加重的疼痛等紧急或严重症状，应立即停止自行处理并联系当地急救服务或尽快前往正规医疗机构。

### 4. 穴位图片与操作边界

穴位图片仅为示意图，不能代替专业取穴，且个体体型与解剖位置存在差异。本产品只提供非侵入性的日常按压参考，不指导针刺、放血、艾灸或其他专业、侵入性操作。皮肤破损、感染、明显红肿或剧烈疼痛处不应自行按压；操作中若出现明显疼痛、头晕、恶心或其他不适，应立即停止。

### 5. 特殊人群

孕妇、儿童、老年人，以及患有慢性疾病、凝血问题、正在服药或近期接受手术的人群，在尝试任何穴位刺激前应先咨询合格的医疗专业人员。

### 6. 内容准确性与审核状态

当前穴位资料和图片属于演示内容，尚未经过执业中医师逐项审核。内容可能存在遗漏、简化或更新不及时的情况，不保证完全准确、完整或适用于每一位用户。

### 7. 隐私与本地运行

本产品在用户设备本地运行，不要求注册，也不会主动上传或保存用户在问诊流程中填写的身体状况。用户仍需自行管理设备、浏览器及本地文件的安全。

### 8. 责任边界

用户应结合自身情况谨慎判断和使用。对于将本产品内容误认为医学诊断、未及时就医或不当自行操作所产生的损失，开发者在适用法律允许的范围内不承担相应责任；法律规定不得排除或限制的责任不受本条影响。

### 9. 更新信息

页面末尾显示“最后更新：2026年10月3日”。

## 技术设计

- 沿用现有单页应用的视图切换机制，新增免责声明视图，不创建第二个 HTML 文件。
- 在现有应用状态与事件委托中增加打开免责声明和返回首页两个动作。
- 免责声明正文直接保存在本地页面中，不从远程服务加载。
- 公共页脚中的入口采用语义明确的链接式控件；视图切换后将焦点移动到免责声明标题，便于键盘和辅助技术用户理解页面变化。
- JavaScript 不可用时，现有 `noscript` 提示继续说明该应用需要启用脚本；不新增联网降级方案。

## 错误与边界处理

- 连续点击免责声明入口或返回按钮不会创建重复内容或破坏应用状态。
- 从问诊过程中进入免责声明后，返回操作固定进入首页，避免恢复到含有敏感健康选择的中间状态。
- 小屏幕上正文保持单栏，链接和按钮保留足够点击区域，不出现横向滚动。

## 测试与验收

- 自动化测试验证首页存在“免责声明”入口。
- 自动化测试验证点击入口后显示标题、九部分核心文案和更新日期。
- 自动化测试验证免责声明页面的“返回首页”操作。
- 自动化测试验证进入免责声明不会触发穴位推荐或修改问诊数据。
- 运行现有完整测试，确认首页、引导问诊、结果页和穴位图片功能无回归。
- 检查 HTML、CSS 和 JavaScript 语法，并在本地文件模式下进行一次桌面与窄屏视觉核对。

## 非目标

- 不提供律师审核结论或针对特定司法辖区的法律意见。
- 不增加用户勾选同意、弹窗强制确认、账户协议或隐私政策页面。
- 不收集、上传或持久化用户健康信息。
- 不将“在线问诊”升级为真实医生服务。
