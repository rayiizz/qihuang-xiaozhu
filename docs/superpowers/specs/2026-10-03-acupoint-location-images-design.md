# 穴位局部定位图设计规格

日期：2026-10-03  
状态：交互设计已批准，等待用户复核书面规格

## 1. 目标

为现有结果页中的 15 个穴位分别增加一张离线局部定位示意图，让用户先通过身体局部和解剖外形标志理解大致位置，再结合现有的一句话文字定位阅读结果。

图片用于辅助理解，不用于诊断、精准取穴、针刺或替代专业人员定位。所有图片与现有穴位数据一样，必须持续显示“演示内容尚未完成专业审核”，直到具备资质的中医专业人员逐图复核。

## 2. 已确认的视觉方案

采用“每穴一张局部放大图”，不使用全身小图，也不在同一卡片同时展示全身图和局部图。

每张图包含：

- 与该穴位相关的单一身体局部。
- 必要的骨性、关节、皮纹或外形标志。
- 一个高对比朱砂色定位点及柔和外圈。
- 简短的方位或标志标注。
- 固定的“位置示意图”视觉标识。

不包含：

- 真人照片或可识别个人特征。
- 针具、进针角度、深度或按压力度。
- 疗效宣称、经络动画或操作步骤。
- 与定位无关的装饰性器官、肌肉或复杂解剖结构。

## 3. 素材格式

图片使用项目内的原创 SVG 矢量示意图，放在：

```text
assets/acupoints/
```

文件名与数据 ID 一致：

```text
LI4.svg
EX-HN5.svg
GB20.svg
LI20.svg
HT7.svg
EX-HN3.svg
GB21.svg
SI3.svg
LI10.svg
PC6.svg
ST36.svg
CV12.svg
GB34.svg
KI1.svg
BL40.svg
```

所有 SVG 使用相同的 `viewBox` 比例、线条语言和颜色变量。文件不引用网络字体、远程图片、脚本、外部 CSS 或嵌入式位图，保证双击 `index.html` 时完全离线可用。

## 4. 图形分组与复用

15 张图片由 10 套局部底图派生，但每个穴位保留独立文件，方便逐图审核与替换。

| 局部底图 | 穴位 | 必须出现的定位标志 |
| --- | --- | --- |
| 手背与虎口 | 合谷 LI4 | 第一、二掌骨、拇指、食指、虎口 |
| 小指侧手部 | 后溪 SI3 | 第五掌指关节、小指、掌横纹末端 |
| 侧头与面部 | 太阳 EX-HN5 | 眉梢、外眼角、颞部凹陷 |
| 鼻面部正视 | 迎香 LI20、印堂 EX-HN3 | 鼻翼、鼻唇沟、两眉头连线 |
| 后枕与肩部 | 风池 GB20、肩井 GB21 | 枕骨下缘、颈后肌轮廓、肩峰、大椎方向 |
| 前臂与腕部 | 神门 HT7、手三里 LI10、内关 PC6 | 腕横纹、尺侧方向、肘横纹、前臂肌腱 |
| 小腿前外侧 | 足三里 ST36、阳陵泉 GB34 | 膝盖、胫骨、腓骨小头 |
| 膝后部 | 委中 BL40 | 膝后横纹、内外侧方向 |
| 上腹部 | 中脘 CV12 | 前正中线、肚脐、胸骨下端方向 |
| 足底 | 涌泉 KI1 | 足底前部、趾根、足弓 |

双侧穴位使用单侧局部图时，图内必须标明“左右同取”或清楚标示左/右方向。不得通过镜像翻转一个带文字的 SVG 来代表另一侧。

## 5. 数据结构

`data.js` 中每个 `acupoints` 项新增：

```js
{
  image: "assets/acupoints/LI4.svg",
  imageAlt: "合谷位置示意：手背第一、二掌骨之间，定位点靠近第二掌骨中点"
}
```

- `image` 必须是项目内相对路径。
- `imageAlt` 必须说明身体局部和定位关系，不能只写“合谷图片”。
- 替代文字与现有 `location` 字段保持一致，但不逐字重复。
- 图片路径和替代文字属于显示数据，不改变症状到穴位的映射。

## 6. 结果卡片

结果卡片顺序为：

1. 穴位名称。
2. 局部定位示意图。
3. 一句话文字定位。
4. 简短禁忌提示。

图片放在语义化 `<figure>` 中，使用数据中的 `imageAlt`。图片区域保持统一比例和纸张底色；SVG 使用 `object-fit: contain`，不能裁剪定位点或方位标注。

图片加载失败时：

- 隐藏该卡片的整个 `<figure>`，不显示浏览器破图图标。
- 保留穴位名称、文字定位和禁忌。
- 不用另一张穴位图代替，也不猜测图片路径。

## 7. 视觉规范

- 底色：暖米色，与当前纸张界面一致。
- 身体轮廓：深墨褐或墨绿细线。
- 结构辅助线：低对比灰褐虚线。
- 定位点：朱砂红实心圆加半透明外圈。
- 文字：深墨色；字号在 360px 宽屏幕上仍可读。
- 图像边界：圆角细边框，不使用照片式阴影。
- 不依赖颜色单独传达定位；定位点同时使用引线或形状差异。

## 8. 可访问性

- 每张图片都有具体且唯一的替代文字。
- SVG 本体不承载必须单独朗读的长段说明，详细信息保留在 HTML 文字定位中。
- 图片放大不会遮挡文字、按钮或其他卡片。
- 200% 浏览器缩放时图片保持完整，不出现水平滚动。
- “位置示意图”和“尚未完成专业审核”不能只画在 SVG 内，HTML 页面中也必须存在。

## 9. 验证

自动检查必须覆盖：

1. 15 个穴位均有 `image` 和非空 `imageAlt`。
2. 15 个图片路径唯一且对应文件真实存在。
3. SVG 文件不含 `http://`、`https://`、`<script>`、`<foreignObject>` 或嵌入式位图。
4. SVG 均包含 `viewBox`，并使用统一定位点类名。
5. 结果卡片正确渲染 `<figure>`、图片路径和替代文字。
6. 图片触发 `error` 时隐藏图框，文字结果仍存在。

人工检查必须覆盖：

- 图中定位点和 `location` 文案一致。
- 左右、前后、掌侧/背侧、足底/足背方向明确。
- 360px 与桌面宽度下定位点和标注均可辨认。
- 键盘浏览结果页时图片不会引入多余焦点。
- 每张图均由中医专业人员逐图审核后才能移除未审核标识。

## 10. 范围之外

- 真人摄影、三维人体、动态图和视频。
- 点击人体部位寻找穴位的交互式地图。
- 图片缩放器、画布拖拽或全屏查看器。
- 针刺、艾灸或按压操作教程。
- 自动生成或推断新的穴位位置。
